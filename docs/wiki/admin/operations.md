# 日常运维（管理员）

## 1. 全局项目管理

在 **管理后台 -> 项目管理**：
- 查看所有项目状态
- 手动触发构建与部署
- 进入构建配置修正参数

## 2. 构建与部署巡检

- 检查构建失败原因（Dockerfile/镜像仓库权限）。
- 确保构建日志正常产出。
- 部署后访问学生域名，确认入口可达。

## 3. 资源巡检

- 检查命名空间资源用量。
- 关注异常 Pod：`CrashLoopBackOff`、`ImagePullBackOff`。

## 4. 备份与持久化

- 数据持久化目录：`/data`
- 备份目标：MinIO
- 建议维护 7/30 备份策略（每日/每周）
